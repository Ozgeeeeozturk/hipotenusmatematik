✖️ Negatif × Negatif Neden Pozitif?

“Eksi çarpı eksi artı eder.” Bu bir ezber değil; matematiğin tutarlı olmasının sonucu.

Soru

(−3) · (−4) = ?

İki negatif sayının çarpımı neden pozitiftir? Bunu, zaten doğru olduğunu bildiğimiz kurallardan mantıkla çıkaracağız.

🧰 Kullanacağımız 3 bilgi

1

Bir sayı ile ters işaretlisinin toplamı 0’dır

4 + (−4) = 0  ·  (−12) + 12 = 0

2

Bir sayının 0 ile çarpımı 0’dır

3 · 0 = 0  ·  (−3) · 0 = 0

3

Çarpmanın toplama üzerine dağılma özelliği

a · (b + c) = a · b + a · c    Örnek: 2 · (5 + 1) = 2 · 5 + 2 · 1 = 12

🪜 İspat, adım adım

  1. 1
    3 · ((−4) + 4) = 3 · 0 = 0

    Isınma: Önce pozitif × negatif ile başlayalım. Parantezin içi 0 olduğu için sonuç 0’dır.

    Neden? 1. bilgi: (−4) + 4 = 0.  2. bilgi: 3 · 0 = 0.

  2. 2
    3 · (−4) + 3 · 4 = (−12) + 12 = 0 ✓

    Aynı işlemi dağılma özelliğiyle yapalım. 3 · (−4), üç tane (−4)’ün toplamıdır: (−4) + (−4) + (−4) = −12.

    Gördük ki: İki yol da 0 veriyor; kurallar birbiriyle tutarlı. Ayrıca pozitif × negatif = negatif olduğunu öğrendik: 3 · (−4) = −12.

  3. 3
    (−3) · (4 + (−4)) = (−3) · 0 = 0

    Şimdi asıl soruya geçelim. Bu kez dışarıda (−3) var. Parantezin içi yine 0, yani sonuç kesinlikle 0.

    Neden? 1. ve 2. bilgi: 4 + (−4) = 0 ve hangi sayıyı 0 ile çarparsak çarpalım sonuç 0’dır.

  4. 4
    (−3) · 4−12 + (−3) · (−4)? = 0

    Aynı işlemi dağılma özelliğiyle açalım. Soldaki çarpımı biliyoruz: (−3) · 4 = −12 (negatif × pozitif, ısınmada gördüğümüz gibi).

    Neden? 3. bilgi: (−3) parantezin içindeki her sayıyla ayrı ayrı çarpılır.

  5. 5
    (−12) + ? = 0

    Sıra sende! Toplamın 0 olması için ? yerine hangi sayı gelmeli?

  6. 6
    (−3) · (−4) = +12

    ? yerine yalnızca +12 gelebilir. O hâlde (−3) · (−4) = +12. İspat tamamlandı! ✅

    Genel kural: Herhangi iki negatif sayı için aynı adımlar çalışır: (−a) · (−b) = a · b, yani sonuç pozitiftir.

🤔 Ya negatif olsaydı?

Diyelim ki biri “(−3) · (−4) = −12” dedi. O zaman 4. adımdaki toplam şöyle olurdu:

(−12) + (−12) = −24  ≠  0  ❌

Ama 3. adımda sonucun kesinlikle 0 olduğunu göstermiştik. Aynı işlem iki farklı sonuç veremez. Kuralların tutarlı kalması için negatif × negatif pozitif olmak zorundadır.

🔢 Bir de örüntüyle bakalım

(−3) ile çarpmaya devam edelim. Sağdaki sayı her seferinde 1 azalırken sonuç nasıl değişiyor?

Sonuç her adımda 3 artıyor. Örüntü bozulmadan devam ederse (−3) · (−4) = +12 olmalı. Bu da ispatımızla aynı sonuç!

🧪 Kendin dene

İki pozitif sayı seç; ispat senin sayılarınla yapılsın.

(−) · (−)
